# 知序 · 经济学学习室

静态中文经济学学习网站，已部署至 https://ranasanny186-png.github.io/fantastic-memory/ 。无需安装依赖、数据库、API 密钥或外部字体。

## 本次更新

在原七章课件基础上，整合用户上传的《微观计算题专项》《微观背诵版资料》和《2022–23(1)微观经济学期末考试题》，新增市场失灵补充章节。共有 83 个知识点、205 道可用题：130 道单选、36 道判断、27 道计算、12 道画图。原 59 个知识点、75 道题的 ID 与内容不变，新增内容追加。

- 知识手册：章节筛选、全文搜索、标记掌握、知识点专项练习。
- 练习：选择题型与章节、顺序或随机抽题、即时解析、错题复习。
- 计算：填写各问数值与推导，按数值答案分项自动评分，支持小数和 `1/3` 形式；只评价数值，不评价过程。
- 画图：手指或鼠标画图，撤销、清空、文字说明；显示本站绘制的参考示意图和评分要点。可改为纸上作图，填写说明后自评。
- 模考：按章节、题型、题数与时长随机组卷，无重复抽题。默认 15 选择×2 分 + 10 判断×1 分 + 4 计算×10 分 + 2 画图×10 分，共 100 分，60 分钟；可调整并动态计算总分。
- 模考作答期间不显示参考答案；答题卡跳题、自动保存、刷新续考、绝对时间倒计时、超时交卷。离开页面不暂停计时，若浏览器关闭，重新进入时按截止时间处理。
- 交卷后显示自动得分、待自评题数与逐题解析。画图由使用者按要点自评，不进行 AI 判图。未自评前不宣称总分为最终成绩。
- 保留当前 / 最近一次完整试卷和最近 20 次成绩摘要，创建新试卷会替换上次完整试卷；历史列表不保留全部答卷。自评修改不重复增加作答次数。
- 手机适配，旧版进度兼容；学习进度可 JSON 导出 / 导入（覆盖前确认）。考试记录保存在单独本地键中，不包含在学习进度备份文件里。

## 启动与打包

```sh
python3 -m http.server 3030 --bind 0.0.0.0 --directory /workspace/fantastic-memory
python3 build.py
```

打包生成 `/tmp/知序-经济学学习室-学习与模考版.html`，可在现代浏览器离线使用。源码版也可直接打开 `index.html`。静态资源附版本参数以避免网站升级时浏览器混用旧逻辑；修改资源后应同步调整版本参数。

## 内容来源与评分边界

- 每张新增知识卡片和每道新增题标明来源。期末卷的 25 道选择、10 道判断、2 道计算已整理。原先 4 道简答现已从所有可用题库入口下架，旧编号留作兼容，相关历史记录保留。
- 原卷未附官方答案，网站使用独立推导的参考答案；对于有歧义的选择题补充条件或消歧，不冒充逐字原题。
- 计算专项按主要题型选编，未声称全部导入。本站核算数值并补充必要假设，纠正原资料中预算式、劳动量文字、税收福利漏计等问题。
- 背诵资料提供补充考点，并非整本复制。新补充章涵盖外部性、公共资源、公共物品、科斯定理和信息不对称。
- 原 PDF、原课件和扫描页不随网站公开发布。参考图为本站按经济学关系生成的定性 SVG。
- 这是个人学习工具，题库与答案在前端可见；计时不能作为防作弊考试系统。成绩和自评只供学习参考。
- 进度、考试、画布与成绩存在当前浏览器 localStorage，无账号及跨设备同步。清理浏览器数据会删除记录。存储不可用或容量不足时界面提示；建议定期备份学习进度。

## 文件

`content.js` 为原始七章数据；`additions.js` 追加前三份 PDF 内容；`textbook.js` 追加高鸿业资料并禁用简答题；`app.js` 管理总览、知识与旧进度；`practice.js` 管理题型、画布、参考图与练习；`exam.js` 管理组卷、持久化、计时与评分；`build.py` 生成单文件版。

## 高鸿业资料更新（2026-10）

新增来源为用户上传的第8版《笔记》和《配套题库》。从复习笔记补充 10 个知识点；精选 / 改写 30 道单选、16 道判断，按复习概念原创 10 道基础计算和 4 道画图，共追加60道。并非整本题库全部导入。

不采用《配套题库》第一部分“考研真题精选”，不采用《笔记》各章“名校考研真题详解”，也跳过章节中带学校、年份与“研”等来源标记的题目。无明确来源、难以恢复的图表、解析矛盾且无法可靠消歧的内容不录入。选择题重新核对选项；判断题按定义核对而非盲信原键，例如原资料把“边际效用为正时总效用增加”标为错误，但解析实际上支持正确，本站明确纠正。

题库仅开放 `choice`、`judge`、`calc`、`graph` 四类。`isActiveQuestion` 和 `activeQuestionIds` 统一约束知识点练习、章节练习、错题列表及模拟考试。简答题保留旧数组位置并标记 `active:false`，不重排后续题目 ID。导入旧学习备份不会删除历史作答；旧版含简答题的完整试卷不再恢复展示，界面提示重新组卷，历史成绩摘要保留。
