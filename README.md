# 知序 · 经济学学习室（七章版）

根据用户提供的七份《西方经济学》课堂课件归纳整理，包含 59 个知识点、75 道原创单选题及逐题解析。

## 使用

无需安装依赖或配置密钥。独立 HTML 版包含所有样式、内容和逻辑，下载后用现代浏览器打开。源码版可打开 index.html，或启动静态服务器：

```sh
python3 -m http.server 3000 --bind 0.0.0.0 --directory /workspace/fantastic-memory
```

本项目没有部署到公共域名。服务器仅供开发使用。

## 功能

- 七章总览、分章节学习进度；知识点全文搜索。
- 知识卡片包含定义、关键公式、适用假设和课件章号/页码。
- 章节练习、知识点专项练习；选择后提交答案，即时显示解析。
- 错题自动收录，重练答对后移出；本轮成绩与累计正确率分开统计。
- 适配手机；图标导航提供无障碍名称。
- 浏览器 localStorage 保存进度；首页支持 JSON 备份导出及导入。导入覆盖前需要确认。

## 内容与进度兼容性

题目为依据课件原创编写，不是课件原题。归纳内容对容易引起误解的表述补充必要假设：如内点解、固定成本不可避免、相同需求和成本下的市场比较、完全竞争和福利定理的适用条件。课件页码以 PPT 幻灯片顺序计数。第四章末页的评析和标准自由进入退出模型分开表述。

前 19 个知识点、前 25 道题保持原版编号与答案位置，沿用 `zhixu-v1` 存储键。同一浏览器和来源下可继续使用原进度；更换文件路径或浏览器可能导致无法自动读取，建议先备份。浏览器阻止本地存储时显示临时模式，可手动导出备份。没有账号或跨设备自动同步。

## 文件

- `index.html`：页面入口。
- `style.css`：响应式样式。
- `content.js`：七章知识与题库数据，新增内容追加，避免改变已有编号。
- `app.js`：导航、练习、错题和进度备份。
- `build.py`：生成不含外部依赖的独立 HTML。
